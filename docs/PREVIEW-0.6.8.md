Not yet approved for GitHub or public release. Extract the complete Electron ZIP and open Shakedown.exe. GitHub source ZIPs are not packaged desktop downloads.

- Fore weapons, aft weapons, and Hangar Pets appear first.

- Supported marks, rarities, and modifiers remain beside item names. IDs and repetitive technical messages move into collapsed Capture details. Conflicting item records remain flagged beside the affected item.

- Includes the Discord footer link, Log Folder platform wording and 00/01/02 numbering, and removal of Download Instructions.

Capture is experimental, read-only, Windows-only, and fingerprinted to the supported STO client. Older cached records can remain; confirm ship and equipment before importing. Item properties describe capture-time observations, not historical loadout-save values. Names and IDs are available more broadly than marks/rarities/modifiers. Traits, bridge officer assignments and effect descriptions remain outside this build.

Review before release: confirm captures for different ships/loadouts against STO; check duplicate-name protection, import to the intended profile, reopen persistence, and selecting the intended variation for a combat run. Category 66 still needs a populated-slot check. No delete-all-data action has been added; it remains on the roadmap.
