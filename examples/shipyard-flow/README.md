# Shipyard workflow preview

Open index.html directly in a browser. No backend, imports, API calls, or persistent storage. All changes reset on reload. Styles and the locally bundled Antonio font are shared with the working app.

- USS Franklin: Beam Broadside and Torpedo Specialist, three variations each. XV has two matching sample runs.
- USS Archer: Cannon Escort, two variations.
- Open Franklin → Beam Broadside → XV. Expand Run history, select both runs, and compare.
- Add run simulates another flight on the same variation. Create variation copies equipment notes but no runs. Archive hides a variation while retaining its history; restore from Archived variations.
- Ship selector is left-aligned alongside the right-aligned Your Shipyard title.

This is a workflow discussion artifact, not the v0.5.2 release or a parser implementation.
