# LCARS color reference

`lcars-classic-theme-colors.png` is the reference image supplied by Kenneth Solans for the Shakedown interface. The image labels its palette “Classic Theme Colors,” updated July 10, 2026. Original creator/source was not supplied; inclusion does not claim authorship of the image.

The interface uses African violet (#baa4e5), almond creme (#fcc19f), butterscotch (#ea9c72), true mauve (#c082a9), and bluey (#8899ff) for its main LCARS accents. All 15 reference colors are defined as CSS variables. Black backgrounds and readable neutral text are retained.
